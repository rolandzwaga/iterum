### 4.2 Deliberate implementation deviations

- **T021 — `Seraphis::mapNoteOnVelocity` has external linkage on purpose.** SC-022 clause 6's
  "127, not 128" upper clamp has no behavioural proxy: the engine divides by 127 and the voice clamps
  to `[0,1]` (seraphis_engine.h:1137, seraphis_voice.h:527), so 128 and 127 render bit-identically.
  Calling the mapping is the only detector. T032 kept it and suppressed
  `misc-use-internal-linkage` with a `NOLINTBEGIN/END` naming the test call site — converting it to
  `static` would be an unresolved external at link time.
- **T021 — an event at exactly `numSamples` is dropped.** `clampOffset` maps `numSamples + 10` to
  `numSamples`, and the loop is `while (cursor < total)`, so the event never comes due. The plan's loop
  was implemented verbatim and the test asserts the observable outcome with a comment. VST3 requires
  `sampleOffset < numSamples`, so no conforming host reaches it — but for a *sloppy* host a note-OFF at
  that offset means a stuck note. Flagged as a behavioural decision a reviewer may want to revisit.
- **T021 — risk R3 ("master gain applied per slice instead of per sample") is NOT detectable by
  SC-008.** The gain atomic defaults to 1.0 linear and FR-024a clause 3 *snaps* the smoother on the
  first block, so per-slice and per-sample cadences produce the identical constant. A real detector
  needs mid-render automation, which SC-008 forbids by construction. The per-sample cadence was
  implemented as specified regardless.
- **T019 — the state test seeds parameters by authoring the byte stream, not by pushing automation.**
  `processParameterChanges()` did not exist yet (T020 owns it). Not circular: every section
  additionally asserts that `getState()` decodes to the *seeded* non-default values by raw byte offset,
  so a `setState()` that ignored its stream or a `getState()` that wrote constants would leave the
  registered defaults and fail.
- **T022 — the agent built and ran the suite despite the "do not build" instruction.** Unavoidable:
  SC-027 clause 2's threshold is required by the spec to be *measured during implementation*, and a
  guessed constant would violate the project rule the task itself cites. Final state green, all
  temporary probes removed.
- **T022 — SC-019 clause 1 as specified was vacuous, and was strengthened.** The spec claims a
  ramped-from-default implementation "fails by design". It does not: replacing `snapTo` with
  `setTarget` leaves the specified 4 s gain-0 render green, because the seam is armed when the engine

  and the section fails.
- **T023 — SC-024's size clause asserts `|big − small| > 1.0` sample, deliberately NOT `big > small`.**

  eliding an unobserved new/delete pair *even when the global allocation functions are replaced*; an
