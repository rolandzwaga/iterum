## 2. Implementation notes — deviations reported by the task agents

Every item below was reported by the agent that wrote the code, not discovered afterwards. The ones that
became formal deviations carry their `D-n` id from `compliance-evidence-r3.md:739-751`.

**T001 — skeleton, ODR sweep, build registration.** ODR sweep
`grep -rn "class AetherReverb\|struct MatrixMorph\|struct BloomBank\|struct ShimmerTap\|struct ChannelState" dsp/ plugins/ tools/`
returned zero output; all five names free. `MatrixMorph` deliberately omitted from the initial state
layout (T003 owns its contents). Reported a transient Clang-only `-Wunused-private-field` set for
skeleton fields no body touched yet, and refused to silence it with a pragma that would outlive the
condition — the set shrank to zero as T002…T012 consumed the fields.

**T002 — geometry.** Shipped `kRefDelays8`/`kRefDelays16` as **public** constants because FR-011's
runtime coprimality companion must name them; added namespace-scope `constexpr` folds plus four
`static_assert`s (the class must be complete first).

**T003 — matrix morph.** Two departures from `plan.md` §7.5's literal recipe, both forced by
measurement: (1) **all matrix maths is `double` internally**, float only at the public boundary — the
plan's cost note assumed float, and double is what makes the 1e-5/1e-6 bounds hold at N=16; (2) **θ is
measured in each emitted plane** (`cos = u1ᵀCu1`, `sin = u2ᵀCu1`) with the plane partner taken from the
antisymmetric part `K = (C − Cᵀ)/2`, instead of the plan's `J = (C − λI)/s` with explicit `λ ≈ ±1`
branches. The literal form was implemented first and measured wrong: on the shipped segment-1 pair at
N=8 it produced `‖VᵀV − I‖_F = 2.83`, because a float-rounded unit eigenvalue turns `sqrt(1−λ²)` into a
noise-driven divisor. No λ epsilon fixes it (a tolerance loose enough for 1e-7 noise wrongly snaps a
genuine 0.0042 angle).

**T004 — FDN core. Two deviations, one of which became a spec amendment.**
(1) **DC blocker normalised** to `y = ((1+R)/2)(x − x[n−1]) + R·y[n−1]`; the bare `fdn_reverb.h:207` form
has `|H| > 1` above ~550 Hz, which inside a recirculating loop is an energy *source* and breaks FR-032
outright (at `decaySeconds = 60` the Nyquist round-trip gain would be 1.0003 and clause C2 would measure
~105 s against 60 s requested). The prefactor leaves the pole, hence the ~40 Hz corner, untouched.
(2) **Input injection placed INSIDE the per-line gain** — `chanIn_[i] = (matrixOut_i + inject_i)·g_i`.
FDNReverb applies its per-line Jot term on the *read* side (`fdn_reverb.h:304`) while its write-side gain
is a single **uniform** base (`:567`); AetherReverb has no base gain, so the literal ordering makes the
injection the only signal that never pays for its transit — **350× (+51 dB)** at SC-005's
`decay 0.5 s / size 1.0` point, measuring **T60 ≈ 0.9 s against 0.5 s requested**. → **D-9**, and
**`spec.md` FR-017 + FR-015a were amended** to the shipped ordering.
Also added `dryScratch*` / `wetScratch*` to the plan's scratch list (step B overwrites `preScratch*`, but
the equal-power mix needs the undelayed dry and the spectral stage needs the whole wet slice).

**T005 — echo density (test-only).** `tasks.md` clause 3's parenthetical "S(1.0)/S(0.25) = 4/0.25 = 16"
evaluates S at size **0**, not 0.25. Under the shipped `S(v) = 0.25·2^(4v)` the correct S ratio is **8**,
and the test implements the binding wording from the same sentence at the unchanged 15 % tolerance.

**T006 — freeze.** Three recorded choices: clause 5 shipped as a separate `[.slow]` `TEST_CASE`
(Catch2 tags are per-case, not per-section); clause 5's ±0.5 dB is measured **within** each frozen hold
(a cycle-spanning comparison at `decaySeconds = 60` would be asserting that `setDecaySeconds` does not
work); clause 3 integrates octave energy over **10 s** windows rather than 1 s — the ±0.5 dB threshold is
unchanged, but at ~1.70 modes/Hz the 125 Hz octave holds ~150 modes at ~0.59 Hz spacing and a 1 s window's
own 1σ spread is ~0.3 dB, the same order as the criterion.

**T007 — life modulation.** **D-5:** SC-017 clause 1a control (ii)'s printed ceiling of 30.5 samples is
unsatisfiable — `kModExcursionFraction` is a **one-sided** amplitude and `BrownianDrift` is clamped to
[−1,+1], so reachable peak-to-peak is **2×** the one-sided figure. Measured directly from `BrownianDrift`:
p-p 1.86…1.99 across three derived seeds ⇒ 47…51 samples on a 5 087-sample line. Ceiling corrected to
61.044; the criterion (must move, bounded by the design excursion + 20 %) untouched. Also: SC-010 clause
2(a)'s "setSeed before prepare" is a no-op for the matrix path by construction (M₂ is built from
`PrepareConfig::seed`), so the test performs **both** the literal call and the matching `cfg.seed`.

**T008 — shimmer.** **FR-059 shelf ships at 120 Hz corner / 0.0 HF gain, not the task's 6 kHz / 0.5**
(a lever the task explicitly authorised, with the shipped values to be recorded). Energy balance: at
send 1 each leg adds `2 × 0.5 / Σm_i = 1.22e-5` per sample of stored-energy growth against Jot
dissipation of only 4.8e-6 at `decaySeconds = 60` — an unshelved ratio of 2.55, i.e. **a net energy
source at every frequency**, which would fail SC-006 clause 1 by 30–70×. A shelf cannot attenuate at DC,
so the corner must sit below the band the (always upward-shifted) returns occupy. Also: SC-006 epoch
definitions follow `spec.md:1620-1621`, not `tasks.md:640`'s shorthand, which matches neither reading.

**T009 — block-partition invariance.** Verification only; the case was already complete. One
comment-only edit refreshing stale `aether_reverb.h` line citations.

**T010 — harmonic bloom. The largest unauthorised addition in the phase.** A **second, out-of-loop**
bloom return ships at `kBloomEmphasisGain = 34.0f`, alongside FR-055's specified in-loop injection, and
